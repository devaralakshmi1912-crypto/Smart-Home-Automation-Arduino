Components Used

- Arduino Uno
- Red LED
- Green LED
- 2 × 220-ohm resistors
- 2 × Push buttons

Working

- Red LED represents the light indicator.
- Green LED represents the fan indicator.
- The first push button controls the red LED ON/OFF.
- The second push button controls the green LED ON/OFF.

Tools Used

- Arduino Uno
- Wokwi Simulator
- Arduino C/C++

Testing

The project was simulated and tested successfully in Wokwi.# Smart-Home-Automation-Arduino
